# WorkReport GPUI 原型

原型有两个入口。「编辑样本」用于检查中文、emoji、表格与 Markdown 保真，样本草稿只保存在内存中。「浏览工作空间」通过与 Tauri 共用的 `workreport-core` 打开本地 Markdown/TXT 日报，按日期查看正文和历史快照。点击「编辑日报」进入编辑，停笔 650 毫秒后自动保存，也可手动保存。双存储沿用本地文件优先和数据库备份规则，仅数据库模式暂由 Tauri 处理。 [迁移计划](../GPUI_MIGRATION_PLAN.md) · [脱敏日报样本](../fixtures/gpui-migration/README.md)

工作空间顶部可输入日期、选择 TXT 或 Markdown 后新建日报。默认日期为本机今天，格式沿用工作空间设置。空白草稿在首次非空保存前保持在内存中，保存后显示在日期列表，文件路径遵循现有目录和命名规则。选择已有日期会打开原日报。

左侧日历提供周、月、年视图，周一开头，方向按钮按当前视图切换时段。「今天」定位本机当前日期。年视图可滚动浏览全年，自动显示当前月份，点击月份标题切回月视图。已有日报在周/月视图显示圆点，在年视图显示为加粗日期。点击已有日期查看原文，点击空白日期进入新建草稿。

周/月日期格显示农历和「休」「班」标记，悬停可查看节名及已有日报的摘要，日期列表也显示摘要。年视图在悬停提示和无障碍名称中提供农历与放假信息，保留紧凑日期格。摘要仅读取周/月可见日期的已有文件，沿用旧版最多读取 16 KiB、截取 80 个 Unicode 字符的规则。保存后刷新，切换工作空间或时段时丢弃旧请求的结果。年视图不读取全年日报正文。

放假信息启动时只读本地缓存。原型优先读取自己的 `holiday-data.json`，缺失时只读旧版 `com.workreport.desktop` 缓存；两者均无数据时沿用旧版离线安排。「同步 年份」只在点击后联网，更新当前显示年度，首次同步会把全部有效旧年度导入原型缓存，旧文件保持原样。同步失败保留有效数据并显示错误，可再次重试；「读取本地」可重读缓存。同步不会改变正在查看的日报或日期范围。代理设置沿用旧版的本机配置。

在任一视图中拖动日期，或按住 Shift 点击另一天，可查看包含起止日期的连续范围，日报按日期倒序排列。月视图的邻月日期可单击打开，拖动框选限于当月。拖动时高亮临时选区，松开后读取范围，在日历外松开也能结束。Esc 或窗口失焦会取消正在进行的拖动。范围预览按原格式分别显示 Markdown 和 TXT，切换「原文」或「复制」可取得带日期分隔的合并内容。范围浏览不创建缺失日期的文件，退出范围恢复先前查看的单日。

## 构建和启动

从仓库根目录运行。使用 Rust 1.99.1 和 `src-gpui/Cargo.lock`。

```sh
./scripts/run-gpui-prototype.sh
cargo test --manifest-path src-gpui/Cargo.toml --locked
```

`--bundle-only` 只生成本地 `.app`，加上 `--release` 可生成优化构建。脚本使用原型专用的应用标识，对本地包做 ad hoc 签名并校验，产物在 `src-gpui/target/bundle/macos/`。

原型运行期间，请先从应用内退出，再通过脚本重启。返回浏览、应用菜单退出和窗口关闭都会先保存草稿。在保存失败时，选择继续编辑或放弃草稿。保存失败后，手动保存成功即可恢复自动保存。

可直接启动到一份样本副本。传入 `--workspace` 后，首个窗口显示该工作空间，应用内选择文件夹仍在后台读取。

```sh
fixture_copy=$(mktemp -d)
cp -R fixtures/gpui-migration/workspace "$fixture_copy/"
./scripts/run-gpui-prototype.sh --workspace "$fixture_copy/workspace"
```

成功打开的目录会原子记录到本机配置目录下的 `com.workreport.gpui-prototype/workspace.json`。下次启动自动恢复，`--workspace` 优先于最近记录。目录失效或记录损坏时，界面保留错误原因，可通过「打开工作空间」重新选择。打开失败会保留上次成功的记录。

原型选用 GPUI Kit `0.10.0` 的默认后端 `gpui-pre 0.3.12`。Kit 提供输入框、Markdown 渲染及无障碍语义，0.10.0 包含与中文组字、字素移动及屏幕阅读器相关的修复。其 macOS 平台依赖启用了 `runtime_shaders`，开发原型可使用 Command Line Tools，将 Metal 着色器编译放在启动时。使用纯 GPUI 手写输入控件时，这些能力需要自行实现和验证。 [GPUI Kit 发行说明](https://github.com/longbridge/gpui-kit/releases/tag/v0.10.0) · [GPUI Kit 依赖配置](https://docs.rs/crate/gpui-kit/0.10.0/source/Cargo.toml)

农历换算固定使用纯 Rust 的 `chinese-lunisolar-calendar 0.2.5`，支持 1901-02-19 至 2101-01-28，范围外省略农历文字。月初显示简体月名，闰月保留「闰」字。 [农历库源码与许可](https://github.com/magiclen/chinese-lunisolar-calendar) · [共享离线放假数据](../shared/calendar/holidays.json)

## 验证步骤

1. 在源码编辑框输入一段中文和 emoji，确认预览同步。用系统输入法分别测试组字确认与取消，再用方向键、Shift 选区、撤销和重做检查光标行为。
2. 在右侧单元格输入框将 `日报` 改为 `中文更新`，点击「应用」。表格和左侧源码应同步变化，从源码区撤销一次应还原。输入竖线、换行或会改变结构的 Markdown 时，原文应保持原样。
3. 点击「复制源码」并粘贴到文本编辑器，核对样本的 YAML 头部、原始 HTML、引用链接及图片语法。预览中的链接为纯文本，图片源被拦截。
4. 用「打开工作空间」或 `⌘O` 打开系统目录选择框，选择脱敏样本副本。点选 11 月 17 日的自定义文件名、18 日的纯文本，以及 19 日的 Markdown 和历史快照。取消选择或打开失败时，先前浏览的工作空间应保留。
5. 在脱敏副本中打开 Markdown/TXT 日报，点击「编辑日报」。连续输入后停笔，检查最新版正文约 650 毫秒后写回。输入完成后立刻返回浏览或关闭窗口，重新打开核对正文与历史快照。也可用「保存日报」或 `⌘S` / `Ctrl+S` 立即保存。
6. 编辑期间从另一个程序改动文件，再保存应显示冲突。尝试返回浏览，在确认框中选「继续编辑」，核对本地草稿和磁盘上的外部修改。用「复制草稿」保留本地内容，可放弃当前编辑并重新加载该日期。切回「编辑样本」后，其草稿也应仍在。
7. 在工作空间顶部选择尚无日报的日期和格式，点击「新建日报」。先关闭空白草稿，确认目录没有新增文件。重新新建并输入内容，停笔后检查自定义文件路径、日期列表和历史快照。退出并重新启动，核对恢复的工作空间及新日报。
8. 分别切换周、月、年视图，检查跨年翻页与「今天」定位。选中十一月日报后切到年图，十一月应在可见区。滚动到十二月并点击月份标题，应进入十二月的月视图。选择月视图的邻月日报，显示月份应保持原样。选择空白日期后关闭草稿，应显示该日暂无日报。
9. 分别在三种视图中正向、反向拖动范围，也可用 Shift 点击。核对范围包含两端、缺失日期未生成文件，TXT 中的 Markdown 标记保持为文字。拖动中按 Esc、拖回起点或在日历外松开，检查不会误开空白编辑器，下次单击仍能正常打开。切换预览和原文，复制后核对日期顺序及 CRLF 原文，再退出范围检查恢复先前的单日。
10. 检查 2026 年 2 月 17 日显示「正月」与春节，2 月 14 日显示「班」。悬停已记录日期查看摘要，编辑保存后核对摘要更新，切换工作空间时不应保留旧目录的摘要。点击「同步 年份」后查看成功或错误信息，已有选区与日报应保持不变；断网重试应保留先前有效安排。正式联网下载由用户手动验证，本轮自动测试使用离线响应。

单元格验证只针对第一个顶层表格的首个正文纯文本单元格。实现用 Markdown AST 定位 UTF-8 字节范围，替换后重新解析，保留范围外的原文。后续富文本实现还需解决多单元格编辑、结构变更、跨块选区、各块间的撤销，以及原生预览与编辑之间的滚动定位。

分栏拖放、历史 Diff/还原和仅数据库模式仍待迁移。Windows 和 Linux 的编译检查由 [GPUI 原型工作流](../.github/workflows/gpui-prototype.yml) 执行。签名升级包、已安装 Tauri 客户端升级和回退验收在正式切换前完成。
