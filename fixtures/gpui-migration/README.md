# GPUI 迁移工作空间样本

样本内容均为虚构。在仓库根目录执行以下命令，为每轮验证创建一份独立副本，保留隐藏索引和历史版本。

```sh
fixture_copy=$(mktemp -d)
cp -R fixtures/gpui-migration/workspace "$fixture_copy/"
printf '%s\n' "$fixture_copy/workspace"
```

在应用里选择打印出的 `workspace` 目录。做双向兼容检查时，先退出写入数据的版本，再用另一个版本打开同一副本。

| 日期       | 验收场景                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| 2026-11-17 | `日报/2026/旧版交接.md` 的文件名不含日期。应用通过 `.workreport-files.json` 将它关联到 11 月 17 日。 |
| 2026-11-18 | 应用继续识别旧目录的 `2026/20261118.txt`，编辑后保存到原文件。                                       |
| 2026-11-19 | 应用按自定义规则找到 `日报/2026/日报_20261119.md`，并显示历史记录里的两个较早版本。                  |

首次打开应从 `ui.axis` 和 `ui.order` 恢复单列布局，依次显示日历、编辑、历史记录，功能栏在左侧。选择 11 月 16 日并创建日报，应按当前设置写入 `日报/2026/日报_20261116.md`。

打开 11 月 19 日的日报后，先退出并用 `cmp` 比较副本与仓库原件，确认只查看时文件字节一致。再用中文输入法输入中英文与 emoji，编辑待办和表格，撤销一次，然后保存、退出并重新打开。核对正文、浏览期间保留的 YAML 头部、HTML、引用链接定义和原始图片标记。历史记录可用来检查差异和恢复行为。
